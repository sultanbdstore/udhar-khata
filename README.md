# 📒 আমার খাতা — অফলাইন পাওনা-দেনা ও ধারের হিসাব

বন্ধু-পরিচিতের সাথে টাকা লেনদেনের (কে কত পাবে / কাকে কত দিতে হবে) হিসাব রাখার বাংলা ডিজিটাল খাতা। **ইন্টারনেট ছাড়াই চলে, কোনো সার্ভার নেই, লগইন নেই, বিজ্ঞাপন নেই।** ফোনে ইনস্টল করা যায় (PWA)।

## ✨ ফিচার
- 👤 **ব্যক্তি অনুযায়ী আলাদা প্রোফাইল** — নাম, মোবাইল, নোট; কল ও মেসেজ বোতাম
- 📜 **তারিখসহ লেনদেনের ইতিহাস** — মাস অনুযায়ী সাজানো, প্রতি এন্ট্রির পর চলতি ব্যালেন্স; এডিট/ডিলিট ও **↩ আনডু**
- 💸 **আমি দিলাম / 💰 আমি পেলাম** — মোট পাবো, মোট দেবো ও নিট হিসাব (লাখ-কোটি কমা, বাংলা অঙ্ক)
- ➕ টাকার ঘরে যোগ করা যায় (`500+250`), বাংলা অঙ্ক/৳/কমা বোঝে
- ⏰ ফেরতের তারিখ ও মেয়াদোত্তীর্ণ সতর্কতা
- 💬 তাগাদা/অনুস্মারক বার্তা (নরম/দৃঢ়) → কপি, শেয়ার, SMS, WhatsApp
- 🏪 **দোকানের বাকি** — মুদি/ফার্মেসি ইত্যাদি দোকান আলাদা প্রকারে যোগ করুন; "বাকি নিলাম" (কী কিনলেন নোট সহ) ও "শোধ দিলাম"; দোকান-ভিত্তিক মোট বাকির রিপোর্ট
- 🧾 জিনিসপত্রের তালিকা (নাম × পরিমাণ × দর → মোট নিজে হয়, আগের দাম মনে রাখে), 🚦 দোকানের বাকির সীমা ও সতর্কতা, 📅 মাসিক সারাংশ, 📤 প্রতি এন্ট্রি দোকানদারকে শেয়ার (দুই পক্ষে একই রেকর্ড)
- 🍽 বন্ধুদের সাথে খরচ ভাগাভাগি, 💬 এক-চাপে তাগাদা, 📇 কন্টাক্ট থেকে নাম (Android Chrome)
- ✅ এক চাপে পুরো শোধ
- 🧾 প্রিন্টযোগ্য স্টেটমেন্ট (PDF সেভ করা যায়) ও টেক্সট শেয়ার
- 📊 রিপোর্ট: শীর্ষ ৫ পাবো/দেবো, মাসভিত্তিক সারাংশ
- 💾 **ব্যাকআপ এক্সপোর্ট/ইমপোর্ট (JSON)** — ঐচ্ছিক পাসওয়ার্ড দিয়ে এনক্রিপ্টেড (AES-256-GCM, PBKDF2 ২ লক্ষ ধাপ); ইমপোর্টে *মিলিয়ে নিন* বা *পুরো বদলান*; শেয়ার-শিট দিয়ে Drive/WhatsApp-এ পাঠানো; Excel-এর জন্য CSV
- 🔐 ৪ অঙ্কের পিন লক, অঙ্ক লুকানোর অপশন
- 🔒 কঠোর CSP — অ্যাপ নেটওয়ার্কে কোনো ডেটা পাঠাতে পারে না

## ⚠️ সীমাবদ্ধতা (সৎভাবে)
- ডেটা থাকে শুধু **এই ফোনের এই ব্রাউজারে (localStorage)**। ব্রাউজার ডেটা মুছলে বা ফোন হারালে হিসাব যাবে — **নিয়মিত ব্যাকআপ নিন** (অ্যাপ ৭ দিন পর মনে করায়)।
- অটো ক্লাউড-সিঙ্ক / একাধিক ডিভাইসে সিঙ্ক নেই; ব্যাকআপ ইমপোর্টের "মিলিয়ে নিন" দিয়ে হাতে মেলানো যায়।
- রিমাইন্ডার নিজে থেকে পাঠায় না, ব্যাকগ্রাউন্ড নোটিফিকেশনও নেই — ফেরতের তারিখ অ্যাপ খুললে দেখায়।
- পিন সাধারণ লক মাত্র; ডেটা ডিভাইসে এনক্রিপ্টেড নয়। সংবেদনশীল হলে পাসওয়ার্ডসহ ব্যাকআপ নিন।
- শুধু ৳; সুদ গণনা নেই। এটি আইনি প্রমাণ নয়, ব্যক্তিগত রেকর্ড।
- Playwright/Chrome-এ পরীক্ষিত; বাস্তব ফোনে সব মডেলে পরীক্ষা হয়নি।

## 🚀 GitHub Pages-এ চালু করুন
1. নতুন রিপোজিটরি বানিয়ে এই ফোল্ডারের **সব ফাইল (লুকানো `.github` ও `.nojekyll` সহ)** আপলোড করুন।
2. **Settings → Pages → Source: GitHub Actions** বেছে নিন (বা Deploy from branch → main / root)।
3. `https://<ইউজারনেম>.github.io/<রিপো>/` খুলে Chrome মেনু → **Install app / Add to Home screen**।

> একবার খুলে নিলে পরে অফলাইনেও চলবে। আপডেট দিলে `sw.js`-এর `VERSION` বদলান।

## 🧮 হিসাবের নিয়ম
ব্যালেন্স = Σ(আমি দিলাম) − Σ(আমি পেলাম)। ধনাত্মক = **আমি পাবো**, ঋণাত্মক = **আমি দেবো**। টাকা পয়সায় (পূর্ণসংখ্যা) জমা হয়, তাই দশমিকের ভুল হয় না। ধার নিলে "আমি পেলাম" চাপুন।
